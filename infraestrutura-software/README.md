# Exclusão Mútua com Algoritmo de Peterson

Implementação em C do algoritmo de Peterson para coordenar duas threads que atualizam um saldo compartilhado. O projeto demonstra concorrência, seção crítica e prevenção de condição de corrida.

## Validar

O repositório mantém a configuração de GitHub Actions recebida com a atividade. Em um ambiente POSIX com `pthread`, compile os arquivos de `src/` juntamente com o teste fornecido pela disciplina.

O código é específico para duas threads, que é a premissa do algoritmo de Peterson implementado.
